# Запись звонков — интерактивный прототип

Демо мобильного приложения Sifox для записи звонков: список звонков, прослушивание, транскрибация разговора по репликам и аналитика вызова.

Прототип — одна страница `index.html`: записи, шрифты и рамка iPhone встроены внутрь, внешних файлов не нужно.

Открыть: https://aaaaaaklyueva-dev.github.io/Call-recorder-/
